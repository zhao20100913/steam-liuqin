## 固件文件（liuqin）

内核 DTS 引用、移植时必须随 rootfs 安装：

```
qcom/sm8475/liuqin/a730_zap.mbn
qcom/sm8475/liuqin/adsp.mbn
qcom/sm8475/liuqin/cdsp.mbn
qcom/sm8475/liuqin/slpi.mbn
novatek/liuqin/novatek_nt36532_m81_fw_csot.bin
```

来源：`zhao20100913/steamos-liuqin1` README。另需 Wi-Fi/BT 固件（`qca6490`/`wcn6855` 系列，通常在 `linux-firmware` 或原厂 `vendor` 分区），待取证确认具体文件名。

## 设备树与地址

- 下游 DTS：`sm8450-mainline/fdt` 的 `liuqin.dts`（另有 `diting.dts` 对照）。
- 主线 DT：`qcom/sm8475-xiaomi-liuqin.dtb`（内核仓构建产物）。
- 校准/唯一数据（触控、指纹、电池、MAC、BT 地址）：只从本机取，放私有备份，禁止跨设备复制。
