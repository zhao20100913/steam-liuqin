# 07 · 安装手册（两步装）

> 目标：平板已用上游 v0.6.0 装好 Ubuntu 双系统并能启动 → 换成 SteamOS。
> 全程需要 PC（adb + fastboot）与平板旁的人；无人值守时不要动启动路径。

## 0. 前置检查

| 项 | 怎么查 |
|---|---|
| 平板已解锁 | `fastboot getvar unlocked` → `yes` |
| 已装 Ubuntu 双系统 | 能启动 Ubuntu，`lsblk -o NAME,PARTLABEL,SIZE` 能看到 `linux_root`(≈32G) 与 `linux_home`(剩余) |
| Ubuntu 里能上网 | `ping -c1 github.com` |
| PC 有 fastboot | `fastboot --version` |

## 1. 下载并校验产物（PC）

从 Release 下载：

- `boot-steamos-liuqin.img` + `.sha256`
- `steamos-liuqin-rootfs.tar.gz.part-*`
- `steamos-liuqin-rootfs.tar.gz.sha256`

```bash
sha256sum -c boot-steamos-liuqin.img.sha256
# 分卷合并后校验（Linux/macOS）
cat steamos-liuqin-rootfs.tar.gz.part-* > rootfs.tar.gz
sha256sum -c steamos-liuqin-rootfs.tar.gz.sha256
```

## 2. 在 Ubuntu 里换根

把 `device/stage-steamos.sh` 拷进平板（或直接在平板上下载），然后：

```bash
sudo bash stage-steamos.sh https://github.com/<you>/<repo>/releases/download/<tag>
```

脚本会：

1. 校验 `linux_root` / `linux_home` 两个分区存在；
2. 把分卷下载到 Ubuntu 根（临时）；
3. **格式化 linux_home**（原 Ubuntu `/home`，会被清空）为 ext4，标签 `LIUQIN_ROOT`；
4. 解包 SteamOS 到该分区；
5. 互换 GPT 分区名：老大根 → `linux_home`，新 SteamOS → `linux_root`；
6. 打印下一步命令。

看完最后几行，**先不要重启**。

## 3. PC 刷 boot（换内核容器）

```bash
adb reboot bootloader          # 或在平板 Ubuntu 里 sudo reboot bootloader
fastboot flash boot_a boot-steamos-liuqin.img
fastboot reboot
```

> 只刷 `boot_a`。`boot_b` 与 Android 保持原样，双系统切换仍可用。
> 想留在 Android：开机时按上游的双系统方式选槽（或 `fastboot set_active b`）。

## 4. 首启预期

构建默认 `debug_boot=1`：`default.target = multi-user.target`，所以第一次**不会**直接进游戏模式/桌面，而是给 TTY + SSH。

- 屏幕：TTY 登录提示（若显示栈没起来，屏幕可能是黑的——不影响下面的判断）
- 键盘（磁吸或 USB-OTG）：`steamos` / 密码 `steamos`
- 网络：`ip a`，Wi-Fi 用 `nmcli device wifi connect <SSID> password <pw>`

验证顺序（一次一项，失败就停）：

```bash
uname -a                       # 6.17 内核
ls /lib/firmware/qcom/sm8475/liuqin/   # 固件在
dmesg | grep -iE 'adreno|panel|novatek|wcd938x' | head
ip a; ping -c1 1.1.1.1
systemctl --failed
```

## 5. 进桌面（验证 TTY/网络之后）

```bash
sudo systemctl set-default graphical.target
sudo reboot
```

首轮大概率不进 gamescope（硬件适配未做）；黑屏就回 TTY：`Ctrl+Alt+F3`，或 SSH 进去 `systemctl status`。

## 6. 回滚

| 场景 | 做法 |
|---|---|
| 想回 Ubuntu（未重启前） | `sudo bash stage-steamos.sh --rollback` |
| 已重启、SteamOS 起不来 | PC：`fastboot flash boot_a <上游 v0.6.0 的 boot.img>` → 回到 Ubuntu |
| 想彻底回 Android | 上游 `install.py --layout dual` 重装，或 `dualboot-tools.zip` 切槽 |
| 分区名改坏了 | PC 上用 `gdisk`/`parted` 看 GPT 名，或 fastboot 重刷上游安装器恢复布局 |

> 上游把 Android 的 `boot.img` 存在 Ubuntu 根（原 `linux_root`）里。换根时我们不格式化它，
> 只把它改名成 `linux_home` 并挂到 `/home`——文件还在，但双系统切换脚本若按旧路径找会找不到。
> 换根前从 PC 另存一份上游 `boot.img`，并确认一次「切回 Android 能启动」。
> 详见 `docs/04-技术债.md`。
