# 04 技术债表

每一条临时做法/未验证假设都登记在此；退出时删除或标「已还」。编号不复用。

| 编号 | 债务 | 影响 | 临时做法 | 退出条件 |
|---|---|---|---|---|
| TD-01 | 根文件系统用 ext4 单根，SteamOS 的 A/B 更新不可用 | 系统更新会写坏盘；用户需手动升级 | 停用 `steamos-update`/相关 timer，文档写明 | 改成 btrfs 子卷 + 自建 A/B 或官方方案 |
| TD-02 | Frame 用户态的 VR 服务裁剪清单未定 | 可能黑屏、耗电、服务反复重启 | 先按 systemd 失败单元逐个 disable，记录白名单 | 形成最小服务集文档，冷启动回归通过 |
| TD-03 | 显示模式/缩放未定 | gamescope 可能黑边比例不对或无法起 KMS | 先固定 2880×1800@120 试跑 | 真机确认模式、缩放、旋转策略 |
| TD-04 | 触摸在 Game Mode 只作指针 | 无手柄时不可玩 | 首版要求蓝牙手柄 | 触摸/虚拟手柄映射方案或明确不支持 |
| TD-05 | 音频 UCM 未接 | 无声 | 先在桌面模式用 PipeWire 手测 aplay | 四扬声器 + 音量键 + 麦克风验收 |
| TD-06 | 休眠/恢复未验证 | 待机耗电/唤不醒 | 首版禁用自动休眠 | 冷启动 + 睡眠恢复验收 |
| TD-07 | 安装器载荷来源与校验流程未改 | 不能一键安装 SteamOS | 先本地替换 rootfs 载荷并核对 hash | 安装器支持本项目载荷与校验 |
| TD-08 | Frame 底包未 pin 到具体哈希 | 版本漂移不可复现 | 首次构建时记录 os-release 与镜像 sha256 | 写进 `inputs.lock` 并由 CI 校验 |
| TD-09 | 指纹/DP/相机未纳入首版 | 功能缺失 | 明确写不支持 | 逐个按第 6 步接入 |
| TD-10 | 内核配置未按 SteamOS 增补 | FUSE/uinput/ntsync 等缺失会导致 Steam/FEX 失败 | 先沿用 liuqin 配置，失败再按需加 | 配置片段进仓库并回归 |
