## 二、用户态组件

| 组件 | 来源 | 备注 |
|---|---|---|
| systemd / SteamOS 基础 | Valve Steam Frame 恢复镜像（btrfs rootfs，约 5 GB） | 需裁掉 VR 服务，保留 systemd、Steam、gamescope |
| Gamescope / Game Mode | 同上 | 需在 msm DRM 上跑通；参考 SteamOSforAlioth、SteamOS-ARM-Port |
| Steam 客户端 + FEX + Proton | 同上 | Frame 自带 ARM64 Steam 与 FEX；x86 游戏靠 Proton ARM64 |
| Mesa / Turnip | Frame 镜像自带 | 版本未知，需实测；a730 需要足够新的 Turnip |
| PipeWire / WirePlumber | 同上 | 加 liuqin UCM/拓扑 |
| NetworkManager / BlueZ / UPower / libinput | 同上 | 基本即插即用 |
| 桌面模式 | SteamOS 自带 KDE（Frame 版可能裁过） | 若缺，可后补 KDE/Plasma 或保留 GNOME 备选 |

## 四、结论

- 内核/启动/分区：**0 行新代码**即可复用，只需按 SteamOS 增补内核配置并在真机回归。
- 用户态：**全部工作量所在**。按「先让 systemd 起来 → 再让图形起来 → 再让 Steam 起来 → 再谈游戏」四层推进，每层都有可判定的完成标准。
- 不需要从零写任何驱动；若 GPU 或音频在 Frame 用户态下不工作，优先换 Mesa/PipeWire 组件版本，而不是改内核。
